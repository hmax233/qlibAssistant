## 使用原则

- 文档中的历史信号不等于今天仍然可买；
- 精确结果以对应分析目录中的CSV为准；
- 带`ideal`的是理想成交，默认应优先看严格`executable/net`口径；
- Test一旦被用于挑参数，就不再是最终未见测试；
- 新实验应追加记录，不覆盖旧结论，错误结论应明确标注修正原因。
