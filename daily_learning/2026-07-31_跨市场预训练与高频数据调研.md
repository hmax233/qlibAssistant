## 三、跨市场模型设计

### 3.1 股票池

- A 股：全部历史主板股票，限定上证 600/601/603/605 和深证
  000/001/002/003，排除科创板、创业板和北交所；
- 美股：当前 S&P 500；
- 港股：当前港股主板列表，训练时按近 252 日成交额取流动性最高 500 只。

使用“当前成分/当前上市列表”会有幸存者偏差。A 股池保留历史退市股票，偏差较小；
港美股第一版偏差更明显，因此港美数据只用于预训练，正式测试只在 A 股主板完成。

### 3.2 因子

脚本生成完整 158 列，字段名与 Qlib Alpha158 一致。Yahoo 没有可靠一致的历史日成交额，
所以 `VWAP0` 在三个市场统一使用 OHLC4 代理。统一代理比在不同市场采用不同定义更适合
迁移学习，但仍应在报告中注明它不是逐笔成交计算的真实 VWAP。

不同市场不拼成一个共同截面：

```text
每个市场按自己的交易日计算时序因子
-> 每个市场、每个日期单独标准化标签
-> 最后拼接训练样本
```

这样不会把春节休市的 A 股和仍在交易的美股错误地当作同一交易截面。

### 3.3 标签与防泄漏

沿用当前项目：

```text
signal at T close
buy at T+1 close
sell at T+2 close
label = close(T+2) / close(T+1) - 1
```

学习目标是同市场、同日的截面 z-score，测试仍使用真实绝对收益。数据段之间预留交易日
间隔，避免前一段最后几个标签跨进下一段。

默认划分：

| 数据段 | 起点 | 终点 | 用途 |
|---|---:|---:|---|
| 全球预训练 train | 2004-01-01 | 2024-07-26 | A+HK+US 学习通用价量模式 |
| A 股微调 train | 2014-07-31 | 2024-07-26 | 继续建树适配 A 股主板 |
| valid | 2024-07-31 | 2025-01-28 | early stopping |
| selection-valid | 2025-01-31 | 2025-07-28 | 选择 global/fine-tune/A-only/混合权重 |
| test | 2025-07-31 | 2026-07-28 | 一次性最终报告 |

test 保持约一年，符合此前“所有方案统一测试窗口”的实验要求。

### 3.4 XGBoost 如何“预训练后微调”

这不是神经网络参数微调，而是：

```text
全球样本训练前 N 棵树
-> 把已有 Booster 作为 xgb_model
-> 只在 A 股主板继续增加若干棵树
```

旧树不会被梯度更新，新树拟合全球模型在 A 股上的剩余误差。因此它更准确的叫法是
continued boosting。为判断迁移是否真实有效，同一流水线还训练 A-only control：

```text
global pretrain
global -> A continued boosting
A-only
global/fine-tuned 不同权重混合
```

只在 selection-valid 上选方案，test 不参与选择。

## 四、首轮小样本结果

冒烟测试规模：

- A 股约 193~197 只；
- 港股 40 只；
- 美股 40 只；
- 全球预训练约 31.6 万行；
- A 股继续训练约 21.5 万行；
- selection 119 个交易日；
- test 240 个交易日；
- 特征 158 + 3 个市场标识。

关键 test 指标：

| 模型 | Rank IC | Rank ICIR | Top10 毛累计 | Top10 扣双边佣金累计 |
|---|---:|---:|---:|---:|
| Global pretrain | 0.0248 | 0.2326 | +13.2% | +1.1% |
| Global -> A fine-tuned | 0.0173 | 0.1526 | +27.0% | +13.4% |
| A-only control | 0.0031 | 0.0256 | -13.3% | -22.5% |

selection-valid 按 Rank IC 最终选择了 global 模型，而不是看到 test 后再改选择。

解读：

- 小样本中，跨市场预训练明显优于 A-only，说明路线值得扩大；
- fine-tuned 的 test 交易收益更高，但 selection Rank IC 没有选中它，不能事后偷换；
- Top1 波动和回撤仍很大，小资金实盘不能因为小样本出现正收益就直接采用；
- 这是 193 只代码靠前的主板股票，不是最终全市场结论。

## 五、Tick、分钟与挂单簿数据

### 5.1 先区分数据层级

| 层级 | 示例 | 能研究什么 | 数据量/成本 |
|---|---|---|---|
| 日线 | OHLCV、复权、资金流 | 日频选股、持有数日 | 最低 |
| 分钟 K | 1/5/15/30/60 分钟 | 尾盘信号、日内路径、执行时点 | 中 |
| Tick/分笔 | 最新价、累计量、逐笔成交 | 微观成交、短周期信号 | 高 |
| Level-2 | 十档、逐笔委托、逐笔成交、委托队列 | 订单流、冲击成本、盘口 | 很高 |
| 完整 order book | 每笔挂单生命周期 | 高频做市、队列位置 | 最高 |

普通行情里的 `tick` 有时只是快照或分笔线，不一定等于逐笔成交，更不等于完整订单簿。
购买前必须确认字段、历史起点、是否包含撤单、逐笔委托和交易所授权。

### 5.2 免费或低成本方案

#### a-stock-data / mootdx

参考仓库 `simonlin1212/a-stock-data` 提供了 A 股多源回退思路：

- mootdx 获取 K 线、当前五档和分笔；
- 腾讯、百度、东方财富作为补充；
- 东方财富资金流。

它适合实时观察和原型验证，但公共接口会限频或变更，历史逐笔深度和稳定 SLA 都不足，
不能视为十年 Level-2 训练库。

#### 当前 Tushare 账号

已经真实调用 `moneyflow` 成功：2026-07-30 返回约 5197 行。该接口 2000 积分即可，
当前 15000 积分足够。它提供 2010 年以来的小/中/大/特大单主动买卖和净流入字段。

重要认识：

> “主力净流入”是供应商按主动买卖方向和金额区间推导出的统计，不代表数据源真的知道
> 某一笔交易背后是机构还是散户。

最近一年已经开始保存到：

```text
/Users/hmax/investment_data/supplemental/moneyflow/
```

#### QMT / XTQuant

迅投官方文档列出基础周期 `tick/1m/5m/1d`，以及
`l2quote/l2order/l2transaction/l2orderqueue`。如果券商账户免费提供 miniQMT，
这是个人研究 A 股实时与分钟数据时最值得先询问的渠道。是否包含 Level-2、可下载多长
历史、是否收费取决于券商和账户等级，不能把客户端 API 存在等同于免费拥有全部历史。

#### iTick

免费档为 5 次 REST/分钟、1 条 WebSocket、3 个订阅；付费个人基础档当前标价
79 美元/月（原价 99），200 个 WebSocket 订阅。覆盖港美和热门 A 股，但购买前仍需
确认目标市场的交易所授权、历史 Tick 深度和是否是完整 Level-2。

### 5.3 较稳定的付费方案

#### Tushare

官方当前个人价格：

- A 股历史分钟（2009 年起）：2000 元/年；
- A 股实时分钟：1000 元/月；
- 港股日线：1000 元/年；
- 港股分钟（2015 年起）：2000 元/年；
- 美股日线：2000 元/年。

这些是独立权限，和 15000 积分无关。Tushare 的历史分钟不是完整 Level-2，也没有
在公开价目中给出 A 股完整逐笔委托/订单簿的个人标准价。

#### 港交所官方历史数据

港交所公开价目示例：

- Bid/Ask Record：500 港元/月；
- Trade Record 月文件：500 港元/月；
- Trade Tickers：1500 港元/月；
- 完整逐单逐笔 Full Book：5000 港元/月；
- 仅逐笔成交 Trade File：2500 港元/月。

这是官方稳定来源，但完整订单簿对个人日频策略性价比低。

#### 美股

Alpaca 免费档只覆盖 IEX 实时流；99 美元/月档覆盖全美交易所、7 年以上历史和更高
调用额度，但它主要解决 consolidated trades/quotes/bars，并不自动等于 Nasdaq
TotalView 完整深度。

### 5.4 暗盘与 dark pool

- 港股“暗盘”多指新股上市前由不同券商内部撮合的 OTC 市场。它不是港交所统一的一本
  完整订单簿，不同券商价格和成交可能不同；通常只能从具体券商获取。
- 美股 dark pool/ATS 的 FINRA 数据可免费获取，但公开的是按证券/ATS 汇总的周度数据：
  Tier 1 通常延迟两周，其他证券通常延迟四周，不是实时逐笔暗池流。
- 网上所谓“实时暗池大单”常是供应商把场外成交报告、延迟报告或大额成交做二次解释，
  不能直接当成机构未来方向。

## 六、最低成本建议

按当前“10 万资金、先做日频/尾盘低频模型”的需求，建议按下面顺序，而不是一开始购买
完整 Level-2：

1. **0 元**：继续日线 + 已有 Tushare `moneyflow`，把资金流做成严格可用时间对齐的
   日频因子；
2. **询问券商，可能 0 元**：申请 miniQMT/QMT，确认是否给 1 分钟、tick 和 Level-2
   历史；先记录未来数据；
3. **2000 元/年**：若确定要做 1 分钟模型，购买 Tushare A 股历史分钟；
4. **暂不建议**：为当前日频策略购买上交所/深交所或港交所完整 order book。

先用分钟数据解决“尾盘决策没有用上当天信息”的割裂感，通常比直接跳到完整逐单订单簿
更符合当前策略频率和资金规模。

## 七、安全与账户风险

当前 Token 来自第三方转售代理。Tushare 官方协议明确不允许在闲鱼等平台转售账号或
权限，因此它可能被限流、改地址或撤销。代码没有把 Token 写进 Git，而是只从：

```text
~/.config/tushare_token
```

读取。长期稳定运行应准备官方自有账号，第三方代理只能作为当前研究过渡。
