# 2026-07-20 正式实验矩阵与实盘验证方案

## 一、研究目标

面向约10万元个人资金，目标不是每天强制交易，而是在 CSI1000 中寻找少量高置信候选，并允许持有现金。最终策略需要同时回答：买什么、是否买、买几只、持有多久、投入多少资金、何时退出。

## 二、需要优化的七个维度

| 维度 | 主要变量 | 首轮建议范围 | 必须固定的条件 |
|---|---|---|---|
| 因子 | Alpha158、因子子集、新价量/基本面因子 | 基线→消融→增量因子 | 相同模型、日期和股票池 |
| 数据范围 | CSI300/500/1000/全A，训练12/24/36/60月 | 先CSI1000，比较24/36/60月 | Point-in-time股票池、相同Test |
| 模型 | Linear、LightGBM、XGBoost、CatBoost | 先单模型，再少量集成 | 相同因子和四段日期 |
| 超参数 | 正则、树深、叶子数、学习率 | 粗网格后局部细化 | selection-valid选参数，Test只看一次 |
| 标签 | 1/3/5日收益、成交价格语义 | 1日与5日优先 | 标签与真实持仓周期严格一致 |
| 选择性交易 | Strength、Persistence、一致性 | Q50/Q70/Q80，AND/OR | 门槛只由selection-valid确定 |
| 组合执行 | Top1/Top2/Top3、持仓期、资金分组 | Top2/Top3优先，Top1专项检验 | 相同成本、可成交性和仓位规则 |

补充的关键维度：成交价格、手续费/滑点、涨跌停与停牌、流动性、股票池历史成分避免幸存者偏差、仓位上限、最大回撤控制、再训练频率以及多重试验导致的过拟合。

## 三、固定的四段数据职责

| 数据段 | 用途 | 禁止事项 |
|---|---|---|
| Train | 拟合模型参数/树结构 | 不得查看后续数据 |
| Valid | LightGBM等模型早停、选择最佳迭代轮次 | 不用于最终报告 |
| Selection-valid | 选择超参数、模型、集成权重和交易门槛 | 不得根据Test反调 |
| Test | 最终一次性评估泛化与交易结果 | 不参与任何选择和阈值设置 |

Linear没有迭代早停；LightGBM的 `l2.valid` 使用 Valid。当前 recorder 集成和 Q70 等交易门槛使用独立 Selection-valid，因此早停与集成/交易规则选择已经分开。

## 五、正式比较训练窗口的方法

不使用“60个月留5个月Test、12个月只留1个月Test”的同比例方案。原因是1个月约20个交易日，评价方差太大，而且不同方案的测试难度与市场阶段不同。

推荐 anchored walk-forward：

1. 每个 Fold 固定同一段约5个月 Test。
2. 固定同一段 Valid 和 Selection-valid，建议各约5个月。
3. 所有训练窗口在同一天结束，只向历史方向改变 Train 起点，例如12/24/36/60个月。
4. 同一 Fold 内所有模型、因子和超参必须使用完全相同的 Test 股票日样本。
5. Fold1/2/3 的 Test 互不重叠，用于覆盖不同市场环境；最终汇总三个 Fold，而不是要求不同 Fold 使用同一个 Test。

示例：Fold3 固定 Valid、Selection-valid、Test 不变，只改变 Train：

| 训练长度 | Train结束 | Valid | Selection-valid | Test |
|---|---|---|---|---|
| 12月 | 均为2025-04-16 | 固定2025-04-17～09-16 | 固定2025-09-17～2026-02-16 | 固定2026-02-24～07-17 |
| 24月 | 同上 | 同上 | 同上 | 同上 |
| 36月 | 同上 | 同上 | 同上 | 同上 |
| 60月 | 同上 | 同上 | 同上 | 同上 |

## 六、评价指标

### 模型层

| 指标 | 作用 |
|---|---|
| IC / Rank IC | 每日截面预测与真实收益的相关性 |
| ICIR / Rank ICIR | 信号跨交易日稳定性 |
| Rank IC正比例 | 有多少交易日排序方向正确 |
| Valid loss与最佳轮次 | 判断欠拟合/过拟合，不直接替代交易指标 |

### 策略与风险层

| 指标 | 作用 |
|---|---|
| 净累计收益、年化收益 | 扣成本后的终值表现 |
| 最大回撤、Calmar | 收益对应的下行风险 |
| Sharpe、Sortino | 波动和下行波动调整后收益 |
| 胜率、盈亏比、期望收益 | 每次触发是否具有统计优势 |
| 交易覆盖率 | 策略多久出手一次 |
| 换手率与成本占比 | 毛收益是否被交易摩擦吞噬 |
| 最差Fold | 市场环境变化时的底线表现 |

### 相对大盘指标（后续必须补充）

| 指标 | 说明 |
|---|---|
| 相对中证1000超额收益 | 策略净值 / SH000852净值 - 1 |
| 超额年化与信息比率 | 超额收益相对跟踪误差的效率 |
| Alpha / Beta | 控制市场涨跌后是否仍有独立收益 |
| 上涨/下跌市场捕获率 | 牛市是否跟得上、熊市是否少跌 |
| 超额最大回撤 | 相对指数净值的最坏回撤 |

当前报告的 `universe_return` 是 CSI1000 样本股票等权平均，不是官方中证1000指数，因此不能替代 SH000852 基准。正式实盘报告需要接入指数行情。

## 七、实验顺序（避免组合爆炸）

1. 冻结三组 Fold 和成交/成本定义，建立不可变基线。
2. 单独比较 Linear、LightGBM、XGBoost、CatBoost，不先调策略。
3. 对最佳1～2个模型做粗超参搜索；只用 Selection-valid排序候选。
4. 固定模型后比较12/24/36/60月 Train，Valid/Selection-valid/Test保持不变。
5. 固定模型与窗口后做因子消融和新增因子实验。
6. 固定信号后比较1日和5日标签。
7. 最后比较Top1/Top2/Top3与Strength/Persistence门槛。
8. 只对少数最终候选运行完整成本、指数基准和模拟实盘。

不要把所有维度一次性做笛卡尔积。大量组合会隐式地在 Test 上挑最好结果，产生回测过拟合。

## 八、单只股票方案

资金有限不等于必须只买1只。现有直接Top1实验跨Fold波动很大，最差结果明显差于Top3，因此暂不采用“无条件买Top1”。下一轮应专项比较：

- Top2等权；
- 在Top3信号触发后，只买Linear与LightGBM共同排名最高且连续上榜的1只；
- 单只股票设置更严格Strength/Persistence门槛；
- 单股仓位不超过总资金的30%～50%，其余现金，而不是默认满仓一只。

## 十、模拟实盘建议

1. 先冻结一个主候选和一个备选，不再根据新Test结果频繁改规则。
2. 使用历史三 Fold 完成最终一次报告后，将其视为封存测试。
3. 开始至少20～40个交易日的每日前向模拟：当晚生成信号，记录次日真实可成交价格，不实际下单或只用极小仓位。
4. 同时记录“模型建议、实际是否触发、计划价格、可成交价格、滑点、持仓、退出原因”。
5. 前向模拟期间只修复程序错误，不调整门槛；期满后统一复盘。
6. 真实投入分阶段：模拟盘→小仓位→达到预设样本数和风险标准后再扩大。

## 十二、统一报告指标与图表解释

`test_report.png` 上方净值图的四根线均从1.0开始：

| 曲线 | 精确定义 |
|---|---|
| Executable TopK Equity | 当前 `--topk`（默认Top10）策略净值；每日取预测排名前K只等资金，按标签持有期采用H组错峰资金。当前1日标签时就是每日换仓。 |
| Executable Universe Equity | 当日CSI1000可用样本股票的截面等权净值，不是官方指数，也不按指数权重。 |
| CSI1000 Equity | 官方中证1000指数SH000852按同一买卖时点计算的净值。 |
| CSI300 Equity | 官方沪深300指数SH000300按同一买卖时点计算的净值，用于观察大盘蓝筹风格。 |

纵轴是净值而非收益率：终点1.35表示累计收益35%。`Executable`表示多日标签时已经使用H个错峰cohort避免重叠收益被重复复利；它不表示已经模拟100股整数手、涨跌停、手续费和滑点。

统一 `summary.csv` 现在必须包含：模型、Train月份与起止、Test起止、Top1/3/5/10胜率和累计收益、同期CSI1000/CSI300累计收益、收益率百分点差值及净值比率超额。两种相对指标分别为：

```text
return_diff = 策略累计收益 - 指数累计收益
excess = (1 + 策略累计收益) / (1 + 指数累计收益) - 1
```
