## 1日、3日、5日标签比较

- 标签定义为下一交易日收盘买入，分别持有1/3/5个交易日到收盘。
- 3日和5日各完成三个 Linear 60个月滚动 Fold，共新增6个 recorder。

| 标签 | Fold1 Rank IC / ICIR | Fold2 Rank IC / ICIR | Fold3 Rank IC / ICIR |
|---|---:|---:|---:|
| 1日 | 0.0391 / 0.3313 | 0.0340 / 0.3162 | 0.0263 / 0.2113 |
| 3日 | 0.0512 / 0.4732 | 0.0564 / 0.4675 | 0.0159 / 0.1212 |
| 5日 | 0.0533 / 0.5007 | 0.0723 / 0.6488 | 0.0097 / 0.0708 |

- 3/5日标签在Fold1/2明显增强排序能力，但在近期Fold3退化得比1日更明显。
- 1日标签的跨时期最低表现更好；3日可能是提高中期信号与保持近期稳定之间的折中候选。
- 3日和5日收益标签在相邻预测日之间会重叠。当前 `evaluate_batch.py` 每日复利曲线会重复计算重叠持仓，所以多日标签的累计收益不能直接与1日标签比较；Rank IC、Rank ICIR和逐日横截面排序指标仍有效。
- 后续需要实现分组错峰持仓或每隔H日调仓，才能公平比较1/3/5日可执行收益。

## 绝对收益标签实验

- 增加 `--raw-label` 开关：标签公式仍是下一交易日收益率，但训练处理器只保留 `DropnaLabel`，不再执行全市场截面的 `CSZScoreNorm`。
- 固定 CSI1000、Linear、60个月窗口、1日标签和相同三个 Fold，与原截面标准化标签进行严格对照。

| Fold | 标准化标签 Rank IC / ICIR | 绝对收益标签 Rank IC / ICIR | 绝对标签 MAE | 绝对标签预测标准差 |
|---|---:|---:|---:|---:|
| 1 | 0.0391 / 0.3313 | 0.0044 / 0.0377 | 1.64% | 0.21% |
| 2 | 0.0340 / 0.3162 | -0.0018 / -0.0167 | 1.90% | 0.21% |
| 3 | 0.0263 / 0.2113 | -0.0066 / -0.0582 | 2.49% | 0.29% |

- raw label 的输出数值已经是收益率单位，但预测波动仅约0.2%～0.3%，真实收益波动约2.5%～3.5%，存在明显向均值收缩。
- 最高预测分位并未稳定获得更高实际收益；Fold3 最高预测分位实际平均收益反而约为 -0.32%。当前不能把 `score > 1%` 当作可靠实盘触发条件。
- 结论：当前 Linear + Alpha158 下，直接学习绝对收益显著损害横截面排序能力。默认生产方案继续保留 `CSZScoreNorm`；raw label 仅作为实验开关保留，后续可尝试 LightGBM、市场收益拆分或单独校准层。
