# 2026-07-20 选择性交易与 LightGBM 超参数实验

## 选择性交易

- 新增 `script/evaluate_selective_trading.py`，直接复用 Linear + LightGBM 三折 recorder。
- 规则阈值只读取 selection-validation 分布，Test 仅用于最终检验。
- 测试 Top3 强度、双模型一致性、前后日排名持续性及简单组合规则；每个交易日按完整换仓扣0.15%成本。
- Fold3 中 persistence Q70 将始终交易的约 -18.3% 改善到 +13.7%，最大回撤由 -31.3% 降至 -8.2%。
- 跨三折看，strength Q70 最差约 -4.0%，persistence Q70 最差约 -6.7%，都比始终交易最差 -18.3%更稳；但平均收益低于始终交易。
- 模型一致性规则没有稳定价值，组合多个门槛造成交易样本过少。
- 结论：先保留 strength Q70 与 persistence Q70 作为研究候选，不接入实盘默认流程。

## LightGBM 超参数

- 新增 `roll/model_params.yaml` 和 `script/run.py --model-preset`，用户可修改 YAML 预设而无需编辑 Python。
- `lambda_l1/lambda_l2/num_leaves/max_depth/min_data_in_leaf` 都属于 LightGBM；Linear 使用 Ridge `alpha`，其他算法各有自己的参数。
- 当前默认 LightGBM 正则为 L1=205.7、L2=581.0，Fold3 Valid 在第0轮最好，显示强正则/欠拟合风险。
- balanced_v1 Fold3：L1=5、L2=20，Valid 最佳轮次变为11；Test Rank IC 0.0069，Top10约 -13.0%。
- low_regularization_v1：L1=0.5、L2=5、depth=6、leaves=63、min_data_in_leaf=200。

| Fold | 默认 Rank IC / Top10 | Low-reg Rank IC / Top10 |
|---|---:|---:|
| 1 | 0.0438 / 50.4% | 0.0438 / 63.7% |
| 2 | 0.0372 / 51.0% | 0.0378 / 25.3% |
| 3 | 0.0103 / -23.1% | 0.0081 / -0.1% |

- Low-reg 显著改善最差 Fold3，但损害 Fold2，暂不替换默认配置。
- 实验日志：`.qlibAssistant/logs/lgb_hyperparams_20260720.log`。

## 选择性交易继续实验

- 明确 Q70 含义：在 selection-validation 的指标分布中取第70百分位作为阈值，不是事后选取 Test 中收益最好的70%。Fold3 Top3 persistence 的Q70阈值为1/3，即今天Top3至少有1只也在昨天Top3才交易。
- Fold3 Persistence Q70：97个测试日触发52日，触发日Top3毛收益均值0.423%，按每日0.15%成本扣除7.8个百分点；净收益逐日复利为13.7255%，胜率53.85%，最大回撤-8.16%。
- Top1/Top3/Top5 对比显示 Top1 波动极大；Top3总体最均衡；Top5 Persistence Q80 三折最差约-0.9%，但总收益较低。
- Top3 `strength AND persistence Q70` 三折净累计约为 -1.1%、+15.3%、+16.3%，分别只交易23、9、26日；跨三段复利约32.6%，接近始终交易约33.3%，但回撤明显更低。Fold2只有9个样本，暂不能认定稳定。
- 评估器新增 `--holding-period`，3/5日标签使用H组错峰资金组合，避免重叠标签重复复利。
- 3日选择性交易改善近期亏损有限：Fold3最佳简单候选约-4.3%，没有扭转为正。
- 5日 `strength AND persistence Q70` 在Fold3约+6.1%，但Fold1约-3.3%、Fold2约+2.0%；Persistence Q70为约+0.5%、+8.1%、+3.6%，防守性较好，但仍只有三个Fold。
- 记录5日Top3 Persistence Q70的完整策略：5日模型每日排名；今天Top3至少2只延续昨天Top3才触发；资金分5个等额 cohort，每日仅一组到期决策，触发则等权持有Top3五个交易日，否则该组留现金；标签按下一交易日收盘进入、第6个交易日收盘退出计算。该错峰策略最多同时存在5批仓位，10万元下会受每批约2万元及100股整数手限制，暂属研究口径。
