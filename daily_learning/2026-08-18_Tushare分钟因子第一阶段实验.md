# 2026-08-18 Tushare分钟因子第一阶段实验

## 目标与结论

目标是验证升级后的 Tushare 历史分钟权限能否在固定样本外框架中改进现有
Alpha158 日频模型，并把“次日涨停买不到”纳入训练和严格回测。

第一阶段结论：**15分钟因子显著提高了横截面 Rank IC，但没有提高严格可交易
收益，当前模型不得替换既有实盘模型。** 主要矛盾仍是模型容易选择 T+1 已涨停
或交易状态异常的强势股；普通按标签复利的回测严重高估了可实现收益。

## 数据权限与落盘

- Tushare `stk_mins` 可用，支持 1/5/15/30/60 分钟历史数据；本实验选择 15 分钟。
- 抽取 CSI1000 主板历史成分的稳定哈希样本 300 只，范围 2019-01-01 至
  2026-08-13。
- 共 1,402 个“股票×年份”分区、5,466,469 根 15 分钟K线、321,557 个股票日，
  下载失败 0，耗时 1,240 秒。
- 原始数据：`.qlibAssistant/supplemental/minute_bars/15min/`
- 权限审计：`.qlibAssistant/audits/tushare_permission_latest.json`
- token 仅从 `~/.config/tushare_token` 读取，不写入报告和日志。

## 因子工程

`script/build_intraday_daily_factors.py` 将 T 日分钟K线聚合成 94 个日频特征，包含：

- 日内收益、实现波动率、下行波动率、偏度、峰度；
- 日内最大回撤/最大上行、振幅、收盘位置；
- VWAP 与收盘偏离；
- 上午、下午、首小时、尾小时收益和成交占比；
- 午间跳空、量价相关、振幅成交量相关、成交量方向不平衡；
- Amihud 日内非流动性、成交集中度/熵、趋势斜率和拟合优度；
- 主要日内特征的 5/20 日后向均值和标准差。

所有 T 日因子只使用 T 日收盘前的数据，只允许用于 T+1 或更晚成交。常数成交量
序列的相关系数明确记为缺失，避免 `0/0` 警告。因子目录：
`.qlibAssistant/supplemental/intraday_daily_factors_15m/`。

## 冻结评测设计

开发阶段只使用 A/B 两折 selection-validation 选模型，C 折 test 在配置冻结后只
打开一次：

| Fold | Train | Valid | Selection-valid | Test |
|---|---|---|---|---|
| A | 2019-01-01~2022-12-31 | 2023H1 | 2023H2 | 2024H1 |
| B | 2019-01-01~2023-12-31 | 2024H1 | 2024H2 | 2025全年 |
| C | 2019-01-01~2024-12-31 | 2025H1 | 2025H2 | 2026-01-01~07-17 |

信号时点为 T 收盘，理论成交为 T+1 收盘，持有至 T+2 收盘。简化成本为完整换仓
0.15%。严格回测额外模拟：涨停不能买、跌停不能卖、停牌/缺报价、无替补时留现金、
持仓状态跨日延续。`event_guard` 使用完整 T+1 日线，属于同Bar理想化探索，不能
作为无偏主结果。

## 原始收益目标实验

A/B 两折比较 Alpha158、分钟因子、两者拼接，以及 XGBoost/LightGBM。按两折
selection Rank ICIR 预选出的配置为 LightGBM + combined：

- A/B 平均 Rank IC = 0.0233；平均 Rank ICIR = 0.2152；
- C test Rank IC = 0.0141；Rank ICIR = 0.0846；
- 同口径 Alpha158 基线 C test Rank IC = 0.0057；Rank ICIR = 0.0408。

分钟因子将 C 折排序指标约提高一倍，但简化 Top1 净累积仅 +5.08%，低于 Alpha158
基线的 +19.80%；Top3/5/10 都为负。

## 可成交收益目标实验

新增 `target=executable`：若未来 T+1 收盘无法买入，则训练标签效用置为现金收益
0；未来成交状态只作为监督标签，不进入特征。A/B selection 胜出配置为
XGBoost + combined：

- A/B 平均 Rank IC = 0.0301；平均 Rank ICIR = 0.2793；
- C selection Rank ICIR = 0.2481；
- C test Rank IC = 0.0129；Rank ICIR = 0.0787；
- C test 简化 Top1 净累积 = -66.26%。

它把严格 Top1 的无法买入次数从原始 combined 的 19 次降到 7 次，但净收益没有
改善，说明“把不可买样本置零”不足以解决择时和收益校准问题。
