# 2026-08-28 Alpha360 概率多任务与跨市场盲测实验

## 1. 本轮目的

本轮不是继续微调旧 Fixed，而是严格比较六种 A 股概率预测结构和一个 A+美股
跨市场扩展。所有模型使用相同 A 股日期切分、Alpha360 定义和训练制度；模型和
ensemble 只能查看 `valid`、`selection_valid`，最终 `test` 在联合选择冻结后才允许
首次物化。

四个预测区间均以信号日 T 为基准：

| horizon | 交易区间 |
|---|---|
| `open1_close2` | T+1 开盘买入，T+2 收盘卖出 |
| `close1_open2` | T+1 收盘买入，T+2 开盘卖出 |
| `open1_open2` | T+1 开盘买入，T+2 开盘卖出 |
| `close1_close2` | T+1 收盘买入，T+2 收盘卖出，和旧 Fixed 标签区间一致 |

目标是概率分布，不只是一个排序分数。每个 horizon 输出对数收益均值、方差、
普通收益期望、普通收益标准差和上涨概率；最终仍需用严格可成交回测判断是否可用。

## 2. 对 8 月 27 日首版说明的正式纠正

8 月 27 日文档记录的是最早版本，后续讨论已经改变训练制度。本轮正式实验以这里
为准：

- 股票身份 embedding 是 **64 维、随机初始化、可学习**，不是冻结的 16 维。
- 使用真实日期 batch：不同日期股票数先 padding，再用 mask 屏蔽；张量形状为
  `[B, N_max, 360]`。不是一次只传一个日期。
- `date_batch_size=4`，每个真实 batch 立即做一次 optimizer step。
- **不使用梯度累积，不使用梯度裁剪。** 源码和任务参数都没有相关操作。
- 完整训练 **50 epoch，不早停**。Valid 只为每个 horizon 保留 RankIC 最高的 epoch。
- AdamW，初始学习率 `3e-4`，weight decay `1e-4`；前 3 轮线性 warmup，之后
  cosine annealing 到 `1e-6`。
- 台式机用 CUDA BF16 编码器；概率分布关键运算保持 FP32。
- RTX 3060 实测 E6：batch 2/4/8 每轮纯训练估时约 93.7/79.6/178.8 秒，
  batch 4 最快。batch 越大不保证越快，因为截面 Attention 的时间/显存随股票数
  近似按 `B*N^2` 增长。

## 3. 固定数据切分与职责

| split | 日期 | 唯一用途 |
|---|---|---|
| Train | 2015-04-17～2025-04-16 | 拟合输入标准化、更新网络参数 |
| Valid | 2025-04-17～2025-09-16 | 每模型、每 horizon 选择最佳 epoch |
| Selection-valid | 2025-09-17～2026-02-16 | 选单模型/Top2/全部等权 mixture，并选择交易规则 |
| Test | 2026-02-17～2026-07-17 | 冻结模型与交易规则后的最终描述性评估 |

有效 Train 共 2402 个交易日、约 240 万股票日；Valid/Selection-valid/Test 分别
约 103/100/99 个可评价信号日。模型权重不能由 Selection-valid 或 Test 反向更新；
交易规则也不能由 Test 挑选。

## 4. E0～E6 模型矩阵

### 4.1 E0：三段联合高斯

E0 先预测三个基础对数收益 `(a,b,c)` 的三维联合高斯：3 个均值和一个 3×3
协方差的 Cholesky 六参数。四种交易收益由线性组合推导，因此能保留区间之间的
相关性。损失是三维联合 Gaussian NLL。

E0 已完成 50 轮，墙钟约 49.8 分钟。各 horizon 的 Valid RankIC 最佳 checkpoint：

| horizon | epoch | Valid RankIC |
|---|---:|---:|
| `open1_close2` | 1 | 0.04825 |
| `close1_open2` | 20 | 0.11467 |
| `open1_open2` | 28 | 0.06044 |
| `close1_close2` | 28 | 0.05915 |

以上只是 Valid 选权重结果，不是 Test，更不是严格收益。E0 的 Selection-valid 已
按 horizon 分别重放，100,000 行；四个 checkpoint 不强制来自同一 epoch。

### 4.2 E1：共享编码器、四个独立高斯头

一个 Alpha360 时间编码器和一个 CSI1000 截面 Transformer，共享股票状态；四个
独立 MLP head 分别输出一个 horizon 的均值和标准差。Loss 是四个独立 Gaussian
NLL 的 mask 均值。

### 4.3 E2～E5：四个完全独立模型

每个交易区间单独训练完整的时间编码器、身份 embedding、截面 Transformer 和
Gaussian head。这样可以判断共享 backbone 的多任务干扰是否伤害某些 horizon，
代价是训练四次。

### 4.4 E6：A 股与美股跨市场模型

E6 输入同一天的 CSI1000 Alpha360 和严格 as-of 对齐的 501 只美股 Alpha360：

- A 股和美股使用 **不同参数** 的时间编码器、时间位置编码、attention pooling、
  股票 embedding 和独立标准化器；不会强行共享行情尺度。
- 每个市场先编码成 64 维股票 token，再拼接 16 维市场 embedding，映射到共同
  64 维空间。
- A 股与美股 token 一起经过 2 层 cross-market Transformer；只对 A 股输出四个
  Gaussian head。
- 美股只能使用中国信号时点之前已经收盘的数据；`same-calendar-day US close` 禁止。

E6 store 含 501 只美股、2706 个 A 股信号日、1,312,437 个美股 Alpha360 行；
输入指纹为：

```text
faad6d003534bd034a26b3ebb57fd62378c07a998e9b433551b6fd303954608a
```

限制：美股池是当前 S&P 500 近似，存在 survivorship bias；所以 E6 能检验“海外
信息是否有增量”，不能据此声称已得到无偏的历史美股 universe。

## 5. 真正的 padded date batch

同一个 batch 内不同日期股票数不同是常见问题，解决方式是 padding 和 mask：

```text
features:  [B, N_max, 360]
stock_ids: [B, N_max]
mask:      [B, N_max]
```

Attention 的 padding key 被 mask，Loss 也只统计 `mask=True` 且标签有限的股票。
因此不会把 padding 当成股票，也不需要用梯度累积伪装大 batch。

E6 有两套独立 mask：`a_mask` 与 `us_mask`。A/US 股票数量可同时变化，padding 后
再进入 cross-market Attention。

## 6. 盲测锁箱与断点恢复

本轮把“看见一个 CSV 就跳过”改成“哈希认证完整才跳过”：

1. 候选必须有配置、数据 manifest、Selection 预测、Selection summary、每个
   checkpoint 的路径与 SHA-256，以及 `test_read=false`。
2. Selection 输出先写到 staging 目录，CSV 和 manifest 通过一次目录 rename
   共同发布；失败不会留下看似完整的半成品。
3. E0～E5 完成后，基础流水线停在 `selection_ready`，明确保持
   `test_access_authorized=false`、`test_read=false`。
4. E6 完成后，按预注册 cross-market protocol 对 E0～E6 的 Selection-valid
   结果统一比较，冻结入选候选及 checkpoint 哈希。
5. 只有联合 manifest 写入后，才物化入选候选的 Test；每个候选和最终 aggregate
   都必须有 completion audit。
6. Test 不能用于改变模型、组合或阈值。后续新设计必须使用未来 lockbox。

原先 6 个严格 `xfail` 契约缺口已全部修复；当前 Alpha360/E6/锁箱相关测试
116 项通过。

## 7. Selection ensemble 规则

每个 horizon 独立比较：

- Eligible：Selection-valid RankIC 有限且大于 0；
- 候选组合：最佳单模型、最佳两模型等权 mixture、所有 eligible 模型等权 mixture；
- 主指标：Selection-valid RankIC；
- tie-break：RankICIR 更高、Gaussian NLL 更低、组件更少。

多个高斯做等权 mixture 时：

```text
mixture_mean = mean(mu_i)
mixture_variance = mean(var_i + mu_i^2) - mixture_mean^2
P(r>0) = mean(P_i(r>0))
```

普通收益期望是各组件 log-normal 期望的平均，不把 mixture 简化成一个高斯后再
错误计算。

## 8. 严格回测口径

模型完成后同时报告 `mainboard`（剔除科创板、创业板）和 `all`：

- 初始资金 10 万元；100 股整数手；
- 买卖佣金各万 2.35，单笔最低 5 元；按用户要求暂不计印花税；
- 同时报 0 bps 与每边 5 bps 滑点；
- 使用 Tushare 原始 OHLC 和逐日精确涨跌停价；
- 涨停不可买时分别支持顺延候选与留现金口径；
- 跌停卖不出则继续持仓，并在以后同一交易阶段逐日重试；
- `open1_close2` 因持仓跨两个交易日，用两个 50% 时间 sleeve，避免资金重复使用；
- Selection-valid 选择不确定度规则，Test 只执行冻结规则；
- 输出净累计、胜率、最大回撤、交易次数、空仓日、涨跌停阻塞、CSI300/CSI1000
  同期收益和超额收益。
